# نظام AbuSaif - تجريد طلبات واتساب

نظام آلي لتجريد الطلبات من جروب واتساب وتسجيلها في Google Sheets.

---

## دليل التشغيل خطوة بخطوة

### الخطوة 1: تحميل المشروع وتثبيت المتطلبات

```bash
cd AbuSaif
npm install
```

### الخطوة 2: إنشاء OAuth Client ID (مرة واحدة فقط)

1. ادخل على: https://console.cloud.google.com/
2. اضغط **Select a project** → **New Project**
3. سمّه: `AbuSaif Bot` → اضغط **Create**
4. بعد الإنشاء، من القائمة الجانبية: **APIs & Services** → **Library**
5. ابحث عن **Google Sheets API** → اضغط عليها → **Enable**
6. من القائمة: **APIs & Services** → **Credentials**
7. اضغط **+ CREATE CREDENTIALS** → **OAuth client ID**
8. إذا طلب منك **Configure consent screen**:
   - اختر **External** → **Create**
   - App name: `AbuSaif Bot`
   - User support email: إيميلك
   - Developer contact: إيميلك
   - اضغط **Save and Continue** حتى النهاية
   - في صفحة **Test users** أضف إيميلك → **Save**
9. ارجع لـ **Credentials** → **+ CREATE CREDENTIALS** → **OAuth client ID**
10. Application type: **Desktop app**
11. Name: `AbuSaif Bot`
12. اضغط **Create**
13. ستظهر لك **Client ID** و **Client Secret** → انسخهما

### الخطوة 3: إعداد المصادقة

```bash
node setup-quick.js
```

سيطلب منك:
- **Client ID**: الصق الذي نسخته
- **Client Secret**: الصق الذي نسخته

ثم:

```bash
node setup-auth.js
```

سيفتح المتصفح → سجّل دخولك بحسابك على Google → اسمح بالوصول.

ستظهر رسالة: **✅ تم تسجيل الدخول بنجاح!**

### الخطوة 4: تشغيل النظام

```bash
npm start
```

عند أول تشغيل:
- سيظهر **رمز QR** في الطرفية
- افتح واتساب → الإعدادات → الأجهزة المرتبطة → ربط جهاز
- امسح رمز QR
- ستظهر **قائمة الجروبات** مع معرفاتها
- انسخ معرف الجروب المطلوب (ينتهي بـ `@g.us`)

### الخطوة 5: تحديد الجروب المستهدف

افتح ملف `config.js` وضع المعرف:

```javascript
targetGroupId: process.env.TARGET_GROUP_ID || '120363XXXXXXXXX@g.us',
```

أو شغّل بمتغير بيئة:

```bash
TARGET_GROUP_ID="120363XXXXXXXXX@g.us" npm start
```

### الخطوة 6: النظام يعمل الآن!

كل رسالة رد تحتوي على (تم / هات / تن / اوك / 👍) ستُسجل تلقائياً في الجدول.

## قواعد النظام

| القاعدة | التفاصيل |
|---------|----------|
| التعريف | يعتمد على **رقم الهاتف** وليس الاسم |
| التفرد | كل عملية لها **معرف فريد** (UUID) لمنع التكرار |
| الحساب | لا تُحتسب العملية إلا **مرة واحدة** |
| السجل | كل عملية تُسجل في **سجل الحركات** |
| الرصيد | يُحسب من **سجل الحركات**، وليس من تعديل مباشر |
| الاستلام | يجب أن تكون **ردًا** على رسالة الطلب |

## كلمات الاستلام

| الكلمة | تحديد الكمية |
|--------|-------------|
| تم | تم = 1، تم 5 = 5 |
| هات | هات = 1، هات 15 = 15 |
| تن | تن = 1، تن 3 = 3 |
| اوك | اوك = 1، اوك 10 = 10 |
| 👍 | دائماً = 1 |
| إيموجي أرقام | 2️⃣2️⃣ = 22 |

### تعديل الكلمات بدون كود

1. افتح الجدول
2. ورقة **الإعدادات**
3. خلية B2: أضف أو احذف كلمات (مفصولة بفاصلة)
4. النظام يحدّث تلقائياً كل 5 دقائق
